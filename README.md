# App Manutenção

Aplicativo web de manutenção integrado ao Firebase Realtime Database.

Projeto Firebase: `appmanutencao-45d05`

Os dados compartilhados ficam no Realtime Database em `appData/`.

## Publicação

Este repositório está preparado para Firebase Hosting. O `firebase.json` usa a raiz do repositório como pasta pública e publica o `index.html`.

## Segurança

As regras atuais do Realtime Database são temporárias para a fase de testes e expiram em 08/10/2026. Antes do uso definitivo, substituir por regras com autenticação.
